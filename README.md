
# Customer Support Ticket Auto-Triage System

## Project Overview
An intelligent ML system for automatic classification of customer support tickets into categories like Technical Issues, Billing Inquiries, Feature Requests, etc.

## Features
- Machine Learning-based ticket classification
- REST API for real-time predictions
- Multi-category classification with confidence scoring
- Easy integration with existing helpdesk systems

## Installation

### Prerequisites
- Python 3.8+
- pip package manager

### Setup
```bash
# Clone the repository
git clone <repository-url>
cd ticket-auto-triage

# Install dependencies
pip install -r requirements.txt

# Run the application
python src/app.py
